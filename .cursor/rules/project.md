# INRIUM — правила проєкту

## Мова спілкування

- Відповідай **українською**.

## Про проєкт

- **INRIUM** — платформа для настільних рольових ігор (користувачі, гравці, майстри, ігрові події, заявки, спільноти, довідники, адмінка).

## Docker-first

- Локальний запуск має працювати через `docker compose up --build`.
- Не покладайся на зовнішні managed-сервіси для базового dev-оточення.

## Поетапна робота

- **Не реалізовуй одразу всі модулі** — рухайся етапами.
- Перед великими змінами показуй **короткий план** (що змінюється, які файли, як перевірити).
- Після кожного етапу **перевіряй збірку** (docker compose config, build, health тощо).

## Безпека та конфігурація

- **Не зберігай секрети в коді** — паролі, JWT-секрети, ключі лише через `.env`.
- Для змін конфігурації оновлюй **`.env.example`**, а не хардкод у репозиторії.

## Обмеження при змінах

- **Не видаляй файли** без явної потреби або прямого запиту.
- Зберігай мінімальний scope diff — не чіпай непов’язаний код.

## Якщо щось не працює

1. Спочатку **поясни проблему** (симптом, причина, що перевірив).
2. Потім **виправляй** — не міняй код навмання без діагностики.

## Стек (орієнтир)

- **Frontend:** Next.js, TypeScript, Tailwind, TanStack Query, React Hook Form, Zod.
- **Backend:** NestJS, Fastify, Prisma, PostgreSQL, JWT, RBAC, Swagger.
- **Infra:** Docker Compose, pnpm workspaces, self-hosted only.
